🎮 Math Quiz Game (C++)

This is my second C++ project, created while completing Course 5: Algorithms & Problem Solving Level 2 on ProgrammingAdvices.
The focus of this project is applying clean code practices, procedural modularity, and safe memory management to build a complete console quiz application.

🕹️ How It Works

1. Select the total number of questions you want to answer.
2. Choose the difficulty level (Easy, Medium, Hard, or Mix).
3. Choose the operation type (Addition, Subtraction, Multiplication, Division, or Mix).
4. Answer each randomly generated question in real-time.
5. Get immediate visual and audio feedback (Green/Red screen and alert sounds).
6. View detailed final results including pass/fail status with an option to play again.

💻 What I Practiced

- Writing clean, self-documenting code with clear naming conventions.
- Decomposing logic into single-responsibility functions (Modular Design).
- Structuring complex game and round data using `struct` and `enum`.
- Efficient memory management using C++ pass-by-reference (`&` and `const &`).
- Random number generation based on difficulty boundaries.
- Separating business logic, arithmetic calculations, and UI presentation.
